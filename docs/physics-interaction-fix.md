# 拖拽姿态与落地回弹修复（2026-09-08）

本次修改基于工作区已有的 upright 三项保护继续修复，保留同步 q、仅修滚转、仅补穿透的行为。

## 原因与改动

- 旋转拟合的协方差读取转置了，目标顶点的旋转也反向使用。两个错误在部分静态姿态下互相掩盖，但 q 与真实姿态不一致，会和回正及装饰件姿态冲突。现在统一为体空间到世界空间的旋转；一个旋转后的无形变星星，原先单个子步产生约 1.434 rad 的姿态误差，修复后低于 0.01 rad。
- upright 在抓取时仍介入，方块摆放会和自动回正较劲。抓取期间现在让位，松手后保留原来的回正策略，不保证任意侧面永久站稳。
- 原沉降逻辑在空中低速阶段也施加强阻尼，静置计时还跨越抓取/松手。现在只有触地、未抓取且持续低速 1.2 秒才施加强阻尼；离地、抓取、高速运动、重置和切换均清除相关计时。
- 复用协方差与旋转缓冲，移除原来每子步创建的两个数组。

没有改动地面碰撞系数、全局阻尼滑块映射、体积约束、限速、舞台边界或引擎冻结区。

## 验证

运行 `node --test scripts/softbody.test.mjs`：11 项通过。覆盖旋转保持、抓取让位、松手计时、三形态定高下落及回弹、软/中/硬模式扰动后运行 30 秒、偏航保护与悬空不上抬、连续切换 12 次与 Reset。测试通过现有 Vite 工具链的 esbuild 加载实际物理源码，不需要 WebGL。

补充确定性测量：默认硬度 1.2、60 Hz、保留环境微颤、静置后整体抬高 1.5 单位。修复前 8 秒仍未触地；修复后苹果约 0.87 秒、星星约 0.95 秒触地，随后向上回弹速度峰值分别约 0.90 和 0.76 单位/秒。该结果说明回弹恢复，不等同于对主观手感的评分。

`npm run build` 通过（已有 bundle 大小提示）；`npx eslint src/three/scene/softbody.ts` 通过。全仓 `npm run lint` 仍有 12 项报错，位于未修改的 UI 组件、hook、SpecimenPanel.tsx 和 Scene.ts。

浏览器补充检查使用 Playwright：方块可从上侧抓取、拉起并改变倾斜方向，已保存抓取截图。浏览器控制台只有 favicon.ico 404。批量截图期间有一次截图超时，因此稳定性结论主要依据上述物理回归测试，而非截图。
